Project 01SOC L1 Project

SOC Home Lab: Log Monitoring & Alert Triage

Built a small Windows and Linux virtual-machine lab, forwarding logs to a free SIEM such as Splunk Free or Wazuh to practise SOC L1 monitoring.

  • Simulated failed-login, brute-force, and port-scan activity using Kali Linux and Nmap.
  • Created SIEM searches and alert rules to detect activity.
  • Triaged true/false positives and mapped findings to MITRE ATT&CK.
  • Documented incident tickets with timelines, evidence, severity, and recommended actions.

Project 02SOC L1 Project

Phishing Email Analysis & Incident Response Playbook

Analysed sample phishing emails and documented a repeatable triage and response process.

  • Inspected email headers, SPF/DKIM/DMARC results, sender details, suspicious links, and attachments.
  • Checked URLs, domains, and file hashes with VirusTotal and recorded IOCs.
  • Wrote a SOC L1 playbook covering triage, escalation, containment, and user communication.
  • Aligned the playbook with NIST CSF.
